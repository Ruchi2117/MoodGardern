## SPA vs API fallback (app.js)

**Source-proven, correct.**

The SPA catch-all in `app.js` guards against the three collision cases:

1. Paths starting with `/api/` are explicitly skipped and fall through to the 404 handler.
2. `/assets/` paths are skipped (static middleware already serves them; the SPA catch-all also skips them).
3. Non-HTML `Accept` headers are skipped — curl/XHR won't accidentally receive `index.html`.

`static.test.js` tests confirm: protected routes return the shell, hashed assets get `immutable` caching, and unknown API paths return JSON 404 rather than an HTML shell. The tests pass this concern.
